# Smart Product Finder 🚀

## 📌 Overview

Smart Product Finder is a full-stack web application that helps users search for products and find nearby stores offering them, sorted by price and distance.

---

## ✨ Features

* 🔍 Search for products
* 📍 Detect user location (Geolocation API)
* 🏪 Show nearby stores with availability
* 💰 Sort results by price and distance
* 🖼 Display product details (via external API)

---

## 🛠 Tech Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* Database: MySQL
* APIs: External product API, Geolocation

---

## 📁 Project Structure

smart-product-finder/
├── client/   # React frontend
├── server/   # Express backend

---

## ⚙️ Setup Instructions

### 1. Clone the repository

git clone <your-repo-link>

### 2. Install dependencies

# Frontend

cd client
npm install

# Backend

cd ../server
npm install

---

### 3. Run the application

# Start frontend

cd client
npm start

# Start backend

cd server
node index.js
